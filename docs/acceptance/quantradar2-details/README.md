# 聚宽式回测详情验收

2026-10-11。用户截图作为布局参考，保留 QuantRadar 标识与本地研究功能。

独立回测详情具有设置/状态栏、左侧导航和白色内容面板。收益概述从原生 metrics.json / risk_metrics.csv 读取，不重新计算；日曲线使用 daily_records.csv 原生百分比。每日盈亏展示取相邻总权益之差，首日使用实际初始权益；不写入指标或历史产物。市值/现金条形图读取日记录。日期筛选包含结束日，支持月/年/全部与对数轴。

交易/每日持仓从原生 CSV 读取，支持列选择、排序、分页、日期筛选及展开按日分组。源码取任务绑定的不可变修订；复制恢复到编辑器仍创建新策略。阶段耗时取任务时间、准备记录和引擎 meta.runtime_seconds。导出沿用注册产物接口。日志使用原增量读取及错误/警告筛选。

引擎未输出阿尔法、贝塔、信息比率、基准波动率等项，显示“—”；未输出函数级 profiler 和 1/3/6/12 月滚动序列，页面明确说明。策略收益页展示原生月度收益表。没有伪造指标、真实交易/社区按钮或覆写原生 HTML。
