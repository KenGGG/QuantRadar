# ETF轮动策略证据补充

## 预先固定的实验设计

用户授权在QuantRadar中补充投资研究证据。全部任务通过本机 `/api/v2/strategies` 和 `/api/v2/runs` 提交，策略名称前缀为 `验证ETF · `，保留原策略不可变修订和历史运行。任务ID、策略ID、源码hash、参数及运行状态见 `manifest.json`。

共25组：原策略全区间复跑1组、基础对照6组、参数扰动8组、成本压力2组、2022年起点1组、后续区间原策略及基础对照7组。没有按结果重新选择参数或只报告最佳结果。

| 实验 | 固定规则 |
| --- | --- |
| 原策略 | 不可变修订20629e741dc54ccdbbe14397c642bca9的原样副本 |
| 四只ETF买入持有 | 单只投入99%，不轮动，不主动再投资现金分红 |
| 等权组合 | 4只各24.75%；每月首个交易日按当时权益恢复等权，先卖后买 |
| 简单动量 | 26个过去交易日收盘价计算25个收益间隔，选收益最高的一只；每日开盘检查，换仓时投入99%，无现金过滤 |
| 参数扰动 | bias_n=48/72；momentum_n=20/30；switch_ratio=1.2/1.8；权重改为各1/3或0.2/0.2/0.6，其他参数固定 |
| 成本压力 | 佣金、最低佣金和固定价格滑点同时扩大2倍/3倍；基金内部管理费已体现在行情中，不再另行扣一次 |
| 不同起点 | 2022-01-01开始，初始50万元 |
| 后续区间 | 2025-12-08至2026-10-12，初始50万元，无参数优化 |

全区间为2019-01-01至2025-12-05。原策略因上市后预热于2019-05-29首次建仓，因此六个基础对照也在该日之前保持现金。参数变更可能改变首笔建仓日期，保留真实源码逻辑并单独披露。后续区间使用此前历史作为合法预热，不使用当日/未来价格评分。

全部使用日频、50万元、沪深300基准、复权参考日2026-10-12；原策略复跑使用已有84根数据对象，其他组固定96根准备窗口覆盖最大参数窗口。准备和校验完成后纯本地回测，不临时联网补数据。佣金0.0003、最低5元、FixedSlippage(0.001)是基准交易成本设定；0.001是价格单位，不是统一的0.1%比例。

收益和风险指标由 `scripts/v2_etf_evidence_metrics.cjs` 直接调用网页 `analytics.ts` 计算，与QuantRadar收益概述一致；原生报告独立保留。全区间开头的现金期计入年化，不掐头；后续不足一年的累计收益优先于年化展示。

## 解释边界

后续区间已存在于历史数据库，这次测试是冻结规则的回溯检验，不是策略事前锁定后收集的前瞻样本外，也不能证明策略设计者从未看过这些行情。跨平台成交对齐证明计算可复现，不能代替独立投资验证。

只有四只预先选定ETF；未排除选池偏差、参数设计偏差及多重检验影响。某个参数表现更好不能据此替换生产策略。日频开盘撮合和固定滑点不是实盘成交证明；历史涨跌停仍沿用引擎估算，QDII交易价、折溢价及实际流动性影响应另作实盘观察。持有指数和基准的风险暴露不同，不能仅凭跑赢沪深300归因于择时。

运行入口：`.venv-v2/Scripts/python.exe scripts/v2_etf_evidence.py submit`。已有manifest时禁止重复提交；使用 `monitor` 接续查询。应用指标：`node scripts/v2_etf_evidence_metrics.cjs`。基线规则测试：`tests/v2/test_etf_evidence_controls.py`。
