# 指标计算与聚宽式编辑页

2026-10-11。用户授权应用层计算此前缺失的指标；历史原生报告与 CSV 不变。

## 计算口径

统一使用 daily_records.csv 每日末值，分钟任务也按日统计。策略/基准日收益从各自累计收益净值的相邻比值取得，首日前净值为 1，保留原生基准参考价及首日收益。250 交易日/年、4% 年无风险利率，标准差使用样本估计（ddof=1）。

| 项目 | 计算 |
|---|---|
| 收益 / 年化 | 日收益连乘净值减 1；净值的 250/n 次方减 1 |
| 超额收益 | 策略净值 / 基准净值 − 1，替代概述中的原生收益相减值 |
| Beta | 策略与基准日收益样本协方差 / 基准日收益样本方差 |
| Alpha | 策略年化 − [4% + Beta × (基准年化 − 4%)] |
| 策略 / 基准波动率 | 日收益样本标准差 × √250 |
| Sharpe | (策略年化 − 4%) / 策略年化波动率 |
| Sortino | (策略年化 − 4%) / [√(平均 min(日收益 − 4%/250, 0)²) × √250] |
| 信息比率 | 平均(策略日收益 − 基准日收益) × 250 / 对应主动收益的年化标准差 |
| 日均超额 / 超额 Sharpe | 日相对收益 (1+策略日收益)/(1+基准日收益)−1 的均值；其复利年化减4%再除以年化波动率 |
| 最大回撤 / 区间 | 净值相对之前峰值的最大跌幅，显示正值及峰谷日期；超额回撤用相对净值 |
| 日胜率 | 策略日收益大于0的天数 / 全部记录天数，含现金 warmup |
| 胜率 / 盈亏次数 / 盈亏比 | 有 realized_pnl_net 的卖出成交记录；盈利笔数 / 已实现成交笔数；正负次数；平均盈利 / 平均亏损绝对值。净盈亏使用引擎分摊费用与分红值，不估算未平仓盈利 |

Alpha 的年化 CAPM 定义参考[聚宽 API 文档](https://cdn.joinquant.com/help/img/JoinQuantAPI.pdf)。本页面公开统一应用统计口径，未声称与聚宽私有实现逐项精确一致。全区间收益、回撤和日均超额以百分比显示；Alpha、波动率、胜率及其他比率使用小数。滚动表收益/回撤均使用小数，与用户截图格式一致。

侧栏全部十项指标提供按月末的 1/3/6/12 个日历月区间统计。少于所需月份或月份缺口显示“—”；首月和末月允许部分月，页面明确说明末月可能未结束。零方差、无亏损、无成交、基准缺失等不产生 Infinity/NaN；无定义项显示“—”。基准缺失后次日不把跨日收益误当单日收益。方差/协方差使用线性计算，详情统计与滚动表缓存，避免增量日志刷新重复计算。

## 编辑页

左右 46%/54% 双栏，深色 Monaco 编辑器、左上保存/编译运行/查找/设置，右上日期/资金/频率与运行回测，六项结果摘要、收益图和底部日志/错误。高级配置与策略管理位于设置弹窗。支持代码查找、自动换行、Ctrl+Alt+B、日志筛选/收起，手机使用上下布局。

编译运行与运行回测均保存新修订并按当前参数提交真实任务，使用同一引擎执行入口；前者不是另一个独立低保真引擎。历史任务恢复仅生成编辑副本。预览明确显示结果所属策略和任务编号。
