## 修复

- 应用QMT Provider依据除权日前一有效收盘价和除权日交易所 `pre_close` 重建基金复权因子。512890使用1.639/0.801形成六位累计因子2.046192；513100使用5.192/1.038形成5.001927。没有硬编码标的价格或导入聚宽CSV作为生产数据。
- 先使用未经复权的QMT OHLC和volume进行比例换算，再按基金三位价格精度舍入；成交量反向复权。缓存记录来源参考价及累计因子，缺失参考价明确失败。校验45个批量/窗口切片后才发布新快照。
- 受成交量上限约束的部分成交保留尾数；原始申报仍按原生规则，资金、费用及持仓账本不改。外部BulletTrade安装文件不修改。
- 索提诺下行风险使用低于当时累计平均收益的日收益子集的样本标准差，年化乘sqrt(250)。以实际聚宽净值交叉验证1.691178，而此前平方偏差总和公式产生1.846383。该筛选/样本标准差口径由用户实际指标和净值验证；[官方API文档](https://cdn.joinquant.com/help/img/JoinQuantAPI.pdf)的下行风险文字不能单独证明这一实现细节。
- 回测编辑区显示提交、排队、运行、完成及失败状态和任务ID，提供详情入口。提交错误直接在编辑区展示；请求超时提示先检查回测列表。代码未改变时复用当前修订。原来成功创建的任务缺少可见状态，容易被理解为按钮无响应。
