# 回测与可复现规范

文件：`docs/04_回测与可复现规范.md`

本文件规定 BulletTrade 回测职责边界、Run 目录、Snapshot、Manifest、Hash 与确定性验收。

数据接口见 `03`，Web 见 `05`。

---

# 一、BulletTrade 职责

BulletTrade 负责全部回测核心，QuantRadar 不得重写：

```text
BacktestEngine
Portfolio
Position
Order
Trade
Scheduler
Commission
Slippage
Dividend accounting
```

若发现 BulletTrade 缺陷：

```text
先写回归测试 → 证明缺陷 → 最小修改（见 00 第四节）
```

---

# 二、正式禁止重写撮合

```text
禁止重写 / 替换 BulletTrade 撮合与组合会计
禁止为「方便」在 Provider 或策略层绕过撮合假设
任何对核心的修改必须有回归测试覆盖，且记录在 CURRENT_STATE
```

---

# 三、Run 目录

每次回测运行落到独立目录：

```text
runs/<run_id>/
├── config.yaml        # 本次回测配置（策略/区间/参数/Provider）
├── strategy.py        # 快照的策略源码
├── result/            # NAV / Position / Trade / Metrics
├── snapshot/          # 完整 Snapshot（见第四节）
└── manifest.json      # 见第五节
```

```text
run_id 由策略哈希 + 配置哈希 + 数据版本生成（见第五节）
禁止：把多次运行混在同一目录
禁止：手动改 result 后宣称复现
```

---

# 四、Snapshot

Snapshot 是「可复现一次实验」的完整状态包：

```text
策略源码
配置
数据版本（investment_data Dolt commit / 数据快照引用）
Provider 版本与参数
依赖版本（BulletTrade / Qlib / Python）
随机种子（如有）
输出结果
```

规则：

```text
Snapshot 必须可独立重跑得到相同结果
Snapshot 不得包含 secrets / 大体积原始数据（引用即可）
```

---

# 五、Manifest 与 Hash

三个哈希共同定义一次运行的可复现身份：

```text
Strategy Hash  = hash(策略源码)
Config Hash    = hash(回测配置 + 参数)
Result Hash    = hash(NAV/交易/指标 输出)
Data Version   = investment_data Dolt commit（或等价数据快照 id）
```

Manifest (`manifest.json`) 记录：

```json
{
  "run_id": "...",
  "strategy_hash": "...",
  "config_hash": "...",
  "result_hash": "...",
  "data_version": "<dolt_commit>",
  "bullet_trade_version": "<commit>",
  "created_at": "..."
}
```

规则：

```text
相同 Strategy + Config + Data Version → 必须得到相同 Result Hash
哈希不一致 → 视为不可复现，必须调查
```

# 六、Deterministic Backtest（确定性回测）

```text
同一份 Snapshot 重跑 → Result Hash 必须一致
禁止：依赖未声明随机性、系统时间、未固定顺序
禁止：回测读取「运行时刻」的最新数据（违反 PIT，见 03）
```

---

# 七、FAILED vs BLOCKED

清晰区分两类「不能跑」：

```text
FAILED   已实现但出错 / 测试不通过 → 缺陷，需回归测试修复
BLOCKED  数据缺失或依赖未就绪，当前不可执行 → 显式标记，不伪造
```

```text
禁止把 BLOCKED 伪装成 PASS
禁止把 FAILED 静默吞成空结果
```

# 八、三个验收策略

Phase 4 回测闭环至少覆盖：

```text
1. Buy & Hold            —— 基准，验证数据→NAV 链路
2. 双均线（DMA）         —— 验证信号→下单→撮合
3. 沪深300动量           —— 验证指数成分/权重（见 03）
```

每个策略需产出并被校验：

```text
NAV 曲线
Position / Trade 明细
Metrics（收益、回撤、换手等）
```

---

# 九、Formal 门禁

进入下一阶段前，回测相关必须达到：

```text
DETERMINISTIC_BACKTEST_PASS
= 三个策略可复现 + Manifest 一致 + 无 FAILED 静默
```

未达门禁不得宣告回测完成，也不得自动进入下一 Phase。
